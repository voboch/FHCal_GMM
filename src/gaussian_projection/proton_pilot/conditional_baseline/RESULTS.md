# Условный банк гауссовских смесей для протонов FHCal

20 ноября 2026 года · Инженерная проверка на отложенных строках

## Как работает бейзлайн

Для заданного направления выбираем с возвращением одну из 32 обучающих
записей этой группы. Из неё берём веса, центры и ширины шести гауссовских
компонент и полный сигнал. Интегрируем смесь по 438 секциям и умножаем доли
на полный сигнал выбранной записи. Для генерации нужны банк, направление и
seed. Все параметры отклика берутся из обучающего банка.

Банк построен на 160 строках протонного архива, по 32 на направление.
Референс — 1 280 отложенных строк из того же файла, по 256 на направление.
Ранее изученные 288 строк исключены. Точных дубликатов записанного
импульса, вершины и отклика среди выбранных строк нет. Результаты относятся
к пяти точным векторам импульса при модуле около 5 в единицах экспорта.
Исходные идентификаторы физических событий и геометрия по ROOT требуют
подтверждения. Вершина участвует в проверке дубликатов, выбор смеси
определяется направлением.

Для интегральной подгонки использованы три старта и лимит 800 итераций
на старт. Из 160 подгонок статус успеха получили 149. Все конечные решения
с минимальной потерей сохранены. Средняя TV реконструкции строк банка —
0,105. Пустых откликов в выбранных строках нет.

## Что сохраняет гладкая смесь

В таблице расстояние Вассерштейна $W_1$ до отложенных строк. Меньше —
лучше. Для каждого направления берём точное эмпирическое распределение
выборки с возвращением и равновзвешиваем пять расстояний. Объединённый
контроль выбирает из всех 160 исходных откликов. Два условных варианта
используют одинаковые 32 строки и веса в каждом направлении.

| Наблюдаемая | Исходные без условий | Исходные по направлению | Смеси по направлению |
| --- | ---: | ---: | ---: |
| Полный сигнал, ед. экспорта | 2,08 | 1,56 | 1,56 |
| Число секций с долей ≥ 1 % | 1,22 | 1,00 | 4,06 |
| Число ненулевых секций | 2,71 | 2,15 | 406,93 |
| Максимальная доля одной секции, п.п. | 1,87 | 3,32 | 4,65 |
| Средняя глубина сигнала, в секциях | 0,119 | 0,276 | 0,281 |

Гладкий декодер сохраняет сумму выбранной записи. По занятости при пороге
1 % переход от исходных откликов к смесям ухудшил $W_1$ на 3,07 секции,
условный 95%-й интервал [2,02; 3,08]. Без порога гладкие компоненты дают
малый положительный сигнал почти по всей карте. Это свойство гладкого
декодирования при текущей карте. Для числа активных секций важен согласованный
уровень считывания или отдельная модель локализации сигнала.

Выборка исходных откликов по направлению снизила $W_1$ полного сигнала
на 0,52 в единицах экспорта по точечной оценке. Интервал для разности
«условный минус объединённый» [−0,50; 0,75] включает ноль. По максимальной
доле и средней глубине меньшие ошибки у объединённого контроля на этом
разбиении. Интервалы получены из 1 000 парных перевыборок внутри направлений
при допущении независимости строк. Банк и референс перевыбирались независимо.
Это сравнение качества при конечном банке из 32 записей на направление.

Точные значения, подгруппы, интервалы, индексы и хеши есть в
[results.json](results.json). Хеш кода в этом файле относится к
квитанции исходной подгонки банка.

## Стохастический декодер приближает распределение числа ненулевых секций

Для каждой компоненты разыгрываем 128 порций. Вероятность попадания
порции в секцию равна нормированному интегралу компоненты по её объёму.
Повторные попадания суммируются. Энергия компоненты распределяется
между порциями поровну, поэтому полный сигнал события сохраняется,
а среднее по многим реализациям при фиксированной смеси совпадает с
гладким откликом. Дополнительный порог считывания не применялся.
Порог 1 % используется при подсчёте одной из метрик.

Число порций выбрано на 640 калибровочных строках. Из девяти вариантов
128 порций дали наименьший $W_1$ числа ненулевых секций среди вариантов,
прошедших ограничения по секциям с долей от 1 %, максимальной доле и
средней глубине. Ниже результаты на 1 280 новых отложенных строках, по
256 на направление. Банк, строки прежней оценки и изученные строки
пилота исключены из обеих выборок. Для стохастического декодера оценены
32 реализации каждой записи банка. Оба варианта используют одинаковые
смеси, суммы и веса. Расстояния $W_1$ усреднены по пяти направлениям.

| Наблюдаемая | Гладкий $W_1$ | Стохастический $W_1$ |
| --- | ---: | ---: |
| Полный сигнал, ед. экспорта | 2,00 | 2,00 |
| Число ненулевых секций | 406,58 | 2,08 |
| Число секций с долей ≥ 1 % | 4,22 | 4,37 |
| Максимальная доля одной секции, п.п. | 4,94 | 4,82 |
| Средняя глубина сигнала, в секциях | 0,311 | 0,310 |

Среднее число ненулевых секций составило 25,66 при 25,74 в референсе
и 432,32 у гладкого декодера. При пороге 1 % обе модели занижают число
секций с заметным сигналом. В среднем их 13,61 у стохастического
декодера, 13,76 у гладкого и 17,94 в референсе. Парная разность $W_1$
для этого показателя равна +0,15 секции с 95%-м интервалом
[+0,03; +0,23]. Интервал получен из 1 000 перевыборок записей банка и
контрольных строк внутри направлений при допущении независимости
строк. Реализации одной записи перевыбирались вместе. Пространственные
корреляции соседних секций требуют отдельной проверки.

## Запустить генерацию

Из корня checkout с установленными зависимостями. Банк уже собран.

```sh
python inference.py -cn=proton_inference inferencer.direction=3 \
  inferencer.events=100 inferencer.seed=17 inferencer.output=outputs/generated_protons.npz
```

Команда читает калибровку из `stochastic_decoder.json` рядом с банком.
Для ручной настройки используется `inferencer.packets_per_component=N`,
для гладкого отклика — `inferencer.decoder=smooth`.

| `--direction` | Записанный импульс $(p_x,p_y,p_z)$, ед. экспорта, округлённо |
| ---: | --- |
| 1 | (−1,037; 0; 4,891) |
| 2 | (−1,028; 0; 4,893) |
| 3 | (−0,160; 0,731; 4,944) |
| 4 | (0,437; 0; 4,981) |
| 5 | (0,621; 0; 4,961) |

В выходном NPZ `section_energy` имеет форму `[events, 438]`. Соответствие
столбцов секциям хранится в `module_id` и `layer`. Поля `weights`, `centers`,
`widths`, `energy` и `source_row` содержат выбранную смесь, её полный сигнал
и индекс обучающей строки в исходном NPZ. Поперечные координаты и ширины
смеси заданы в сантиметрах, продольные — в единицах индекса секции.
Повтор с тем же seed воспроизводит выборку. Подгонка новых кодов нужна
только при пересборке банка. В выходе `decoder` указывает режим,
а `packets_per_component` содержит число порций (0 в гладком режиме).

Для повторения измерения использовать точный протонный NPZ из
`virtual_grid-gnn` на `2007441` и новую выходную директорию.
[Происхождение и протокол](../../../../docs/experiment_protocol.md#инженерный-прогон-банка-смесей-на-протонах).

```sh
python train.py -cn=proton data.path=data/fhcal_data_side_modules81619_180.npz \
  run.output_dir=outputs/proton_replay trainer.workers=4
```

Повторить калибровку и сравнение при зафиксированном банке можно командой

```sh
bank_dir=src/gaussian_projection/proton_pilot/conditional_baseline
mkdir -p outputs/proton_replay
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
  python src/evaluate_gmm_packet_decoder.py data/fhcal_data_side_modules81619_180.npz \
  "$bank_dir/bank.npz" --output outputs/proton_replay/stochastic_decoder.json
```
