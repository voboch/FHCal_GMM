# Выбор секций с положительным сигналом при известной сумме

24 ноября 2026 года. Протокол записан до расчёта метрик нового преобразования. Повторно используем контроль парного опыта [при известном суммарном сигнале](../conditional_shapes/PROTOCOL.md). Результаты исходных моделей на этом контроле уже изучались.

**Гипотеза.** Число положительных секций из обучающей карты и ранжирование секций по прогнозу WGAN-GP уменьшают ошибку секционных вероятностей срабатывания при сохранении точности модульных хвостов. Механизм проверяем отдельно для прямой WGAN-GP и WGAN-GP с интегральной GMM. Положительный сигнал определяется в шкале архива условием Eₛ > 0. Аппаратный порог в этом опыте не вводится.

**Выборки и преобразование.** Сохраняем прежние 4096 записей на направление в каждой из трёх ролей (обучение, калибровка, контроль), три мюонных и пять протонных направлений, три фиксированные инициализации каждой сети. Для каждой контрольной записи задаём её наблюдаемую сумму T. Генерируем исходную карту, затем из 16 ближайших по log T обучающих записей в том же направлении равновероятно выбираем донора. Обе архитектуры получают одного донора. Для k положительных секций донора сохраняем k наибольших сигналов исходной карты и нормируем сумму к T. При равных значениях используем порядок секций геометрии. Если в исходной карте положительных секций меньше k, сохраняем их все и считаем такие случаи. Нулевая сумма даёт нулевую карту. Эмпирический контроль использует всю секционную форму того же донора. Усечение применяется после обучения, гиперпараметры зафиксированы.

**Метрики.** Сравниваем с транспортной симуляцией. (1) Средняя по 438 инструментированным секциям абсолютная ошибка вероятности Eₛ > 0, п.п. (2) Расстояние Вассерштейна W₁ между распределениями числа положительных секций, в секциях. (3) Средняя абсолютная ошибка безусловной частоты превышения модульного q95, п.п. Порог для каждого модуля и направления определяется по положительным калибровочным сигналам при наличии ≥500 таких записей. Знаменатель для частоты включает все контрольные записи направления. Усреднение равновесное по секциям (или пригодным модулям) внутри направления, затем по направлениям, затем по трём запускам. Публикуем метрики по каждому направлению и запуску, размах по запускам характеризует вариацию на фиксированном контроле.

**Решение.** Для каждой архитектуры сохраняем механизм кандидатом для следующей независимой проверки, если в среднем по трём запускам ошибка секционных частот уменьшается для обоих видов и у каждого вида ошибка модульных хвостов не возрастает. Улучшение одного распределения k ожидаемо по построению. Физический допуск по этим метрикам не установлен. Вывод ограничен отдельными частицами, изученными направлениями и заданной суммой.
