# Разреженность секционного отклика при заданной сумме

При заданном суммарном сигнале выбор числа положительных секций по обучающей записи уменьшил ошибку вероятности положительного сигнала в отдельных секциях обеих WGAN-GP. После перенормировки выросла ошибка частоты превышения модульного q95. Рост наблюдался при каждой из трёх инициализаций, для обеих архитектур и обоих видов частиц. По [заранее заданному критерию](PROTOCOL.md) такой способ отбора секций не прошёл проверку.

| Вид частиц | Генератор | Ошибка вероятности Eₛ > 0, п.п. | W₁ числа положительных секций, секции | Ошибка частоты превышения q95, п.п. |
|---|---|---:|---:|---:|
| µ⁺ | Прямой WGAN-GP | 97,930 → 0,155 | 428,93 → 0,05 | 1,773 → 1,917 |
| µ⁺ | WGAN-GP с GMM | 37,079 → 0,353 | 162,39 → 0,05 | 3,805 → 4,058 |
| µ⁺ | Эмпирическая форма | 0,028 | 0,05 | 0,340 |
| p | Прямой WGAN-GP | 94,190 → 4,486 | 412,55 → 0,25 | 2,260 → 2,462 |
| p | WGAN-GP с GMM | 77,870 → 4,813 | 341,06 → 0,25 | 4,438 → 4,470 |
| p | Эмпирическая форма | 0,316 | 0,25 | 0,303 |

Стрелки показывают значения до и после преобразования одной и той же сгенерированной карты. Число k положительных секций берём у одной из 16 ближайших по log T обучающих записей того же направления. Оставляем k наибольших секционных сигналов WGAN-GP и нормируем сумму к наблюдаемому T. У каждой модели для каждой карты нашлось k положительных секций. Поэтому распределение числа секций после отбора совпало с распределением у эмпирической формы до округления. Различие ошибок секционных вероятностей отражает выбор позиций. В частности, у протонов ошибка после отбора составляет 4,49 и 4,81 п.п. для прямой модели и GMM соответственно, у эмпирической формы — 0,32 п.п.

**Область оценки.** Данные транспортной симуляции включали 12 288 мюонных и 20 480 протонных контрольных строк по трём и пяти направлениям. Для каждой физической секции вероятность положительного сигнала определена на всех строках при фиксированном направлении. Секционные ошибки усреднены по 438 секциям. Точные нули относятся к численному представлению отклика. Соответствие условию срабатывания электроники требует отдельной калибровки. Для каждого пригодного модуля порог q95 взят по положительной калибровочной выборке соответствующего направления, знаменатель частоты включает все контрольные строки. Сначала усредняли по пригодным модулям, затем поровну по направлениям и трём запускам. Рост ошибки q95 для протонной GMM составил от 0,027 до 0,041 п.п. по запускам. Независимая статистическая значимость этой небольшой разности не установлена. Использован уже изученный контроль при наблюдаемом T. Независимость архивных строк по идентификаторам первичных событий требует проверки.

## Воспроизведение

Из корня FHCal_GMM с подготовленными секционными картами и весами [опыта при известной сумме](../conditional_shapes/RESULTS.md) выполните:

```sh
OPENBLAS_NUM_THREADS=1 MPLBACKEND=Agg python src/evaluate_section_sparsity.py
```

Скрипт сверяет метрики исходных моделей с опубликованным экспортом, проверяет неотрицательность карт, сохранение полной суммы и число положительных секций после отбора.
