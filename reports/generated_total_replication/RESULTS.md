# Генерация суммы и формы на втором транспортном контроле

На 12 288 других мюонных и 12 288 других протонных записях наименьшую среднюю ошибку частоты превышения модульного q95 вновь дала эмпирическая форма. Среди двух WGAN-GP меньшая ошибка у прямого выхода. Для этой проверки сохранены те же сгенерированные суммы CFM, карты, калибровочные пороги и обученные модели. Изменился только контроль транспортной симуляции.

| Ошибка частоты превышения q95, п.п. | µ⁺, прежний контроль | µ⁺, новый контроль | p, прежний контроль | p, новый контроль |
|---|---:|---:|---:|---:|
| CFM и эмпирическая форма | 0,81 | 0,61 | 0,34 | 0,33 |
| CFM и прямая WGAN-GP | 2,24 | 1,98 | 2,31 | 2,30 |
| CFM и WGAN-GP с интегральной GMM | 4,28 | 4,11 | 4,61 | 4,59 |
| Расхождение между контрольными выборками | | 0,41 | | 0,25 |

Каждая пара столбцов относится к одним направлениям с 4096 строками в каждой контрольной выборке. Для мюонов это направления 1–3 (6 пригодных пар «модуль, направление»), для протонов — 1, 3 и 5 (67 пар). Для каждого модуля сравнивались частоты строгих превышений среди всех строк. Модули имеют равный вес внутри направления, направления и три реализации формы также имеют равный вес. Расхождение между контролями даёт сравнительный масштаб вариации на этих двух выборках. Диапазоны трёх реализаций и полная точность чисел доступны в [экспорте](summary.json).

В третьем мюонном направлении ошибка у WGAN-GP с GMM составила 1,75 п.п., у прямой — 3,19 п.п. Это ограничивает вывод о преимуществе прямой модели при выборе конкретного направления. Ещё в двух протонных направлениях сохранилось 502 и 591 новая запись. На них ошибки для эмпирической формы, прямой WGAN-GP и WGAN-GP с GMM составили соответственно 0,66 / 2,09 / 4,69 и 0,56 / 2,33 / 3,89 п.п. Эти направления оценены отдельно в соответствии с [протоколом](PROTOCOL.md).

Новые строки извлечены из тех же двух архивов. Проверена непересекаемость индексов и точных пар «вершина, секционная карта» внутри каждого направления со всеми записями из манифестов обучения, калибровки, предыдущих контрольных выборок и ранних диагностик. Независимость первичных событий требует подтверждения по их идентификаторам. Проверенный порядок относится к данным конфигурациям генераторов и известным направлениям.

## Воспроизведение

Из корня FHCal_GMM выполните команду с двумя распакованными архивами, описанными в [PIPELINE.md](../../PIPELINE.md). Входные счётчики генераторов находятся в [отчёте о сквозной генерации](../generated_total/RESULTS.md). Для каждой модели и каждого пригодного модуля скрипт сверяет прежний контрольный счётчик с пересчётом из исходного архива. Пороги и прежние прогнозы сохраняются при переходе на новые строки.

```sh
python src/replicate_generated_total.py \
  --muon data/fhcal_data_muons_81619.npz \
  --proton data/fhcal_data_side_modules81619_180.npz
```

Индексы новых строк, хеши архивов, исходных манифестов и применённых экспортов сохранены для [мюонов](muon_reference.json) и [протонов](proton_reference.json). Числа превышений по модулям приведены для [µ⁺](muon_modules.csv) и [p](proton_modules.csv), средние ошибки по отдельным направлениям — для [µ⁺](muon_directions.csv) и [p](proton_directions.csv).
