# Повторная оценка генераторов на других транспортных записях

Зафиксировано 24 ноября 2026 года после проверки числа доступных индексов, до вычисления секционных сигналов новой выборки и ошибок моделей. Проверяем, сохранится ли в среднем по направлениям порядок средней абсолютной ошибки частоты превышения q95 «эмпирическая форма, прямая WGAN-GP, WGAN-GP с GMM» при замене транспортного контроля. Используем сохранённые прогнозы опыта с суммой от CFM, его пороги калибровки и список модулей. Модель, её шум и число генераций фиксированы.

Из каждого прежнего направления берём до 4096 других строк из того же файла. Исключаем индексы ранних диагностик, все роли выборок single_particle и контроль conditional_shapes. Внутри направления исключаем также точные совпадения пары «вершина, карта по 438 секциям» со всеми перечисленными строками и между новыми строками. Размещаем кандидатов в случайном порядке без возвращения, seed 261124, отдельный поток для каждого вида и направления. В первичный итог с равным весом направлений входят группы с 4096 оставшимися строками. В двух протонных направлениях перед проверкой дубликатов осталось 502 и 591 записей. Для них приводим отдельные оценки без включения в первичный итог.

Для каждого модуля с ≥500 положительных сигналов на исходной калибровке фиксируем её положительный q95. Частоту строгих превышений считаем среди всех строк своего направления. Абсолютные отклонения двух частот, в процентных пунктах, усредняем сначала по модулям, затем по полным направлениям, затем по трём реализациям формы. По тому же правилу вычисляем расхождение прежнего и нового контроля. Дополнительный ориентир для порядка методов — отдельные ошибки по каждому направлению и реализации. Для подтверждения порядка в этой выборке требуем сохранения ранжирования по средней ошибке на каждом виде частиц. Физического допуска на ошибку и подтверждённых первичных ID нет. Эти данные проверяют чувствительность к выбору контрольных строк данного архива.
