# Парное сравнение генераторов формы при известном суммарном сигнале

Проверяем, как параметризация формы влияет на хвосты модульного сигнала и продольную структуру. В обеих ветвях условного WGAN-GP используем одно направление и одну наблюдаемую сумму T на контрольную строку. Обучаем одну модель на вид и представление. В первой ветви генерируем параметры интегральной GMM (4 компоненты для мюонов, 6 для протонов по предыдущему пилоту), во второй непосредственно генерируем 438 неотрицательных долей. Эмпирический контроль выбирает форму среди 16 ближайших по log T обучающих записей того же направления. Начинаем с WGAN-GP, поскольку обе его ветви можно обучить на одних секционных картах без предварительной подгонки смесей к каждой из них.

Используем по 4096 прежних обучающих и калибровочных записей на направление. Для контроля выбираем 4096 других строк того же направления из исходного архива, исключив ранее использованные индексы и совпадения пары «вершина, секционный отклик». Для каждого вида и представления заранее фиксируем 3 инициализации, 800 шагов генератора, 3 шага критика на шаг генератора и размер батча 64. Это единый бюджет разведочного сравнения. Сеть получает направление, нормированный log T и независимый шум. Гиперпараметры по контролю не подбираем.

Основная метрика — абсолютная ошибка безусловной частоты превышения q95 положительных калибровочных сигналов модуля (п.п.). Порог включается при ≥500 положительных записях калибровки. Сначала усредняем ошибки по модулям внутри направления, затем по направлениям с равным весом. Дополнительно измеряем расстояние Вассерштейна W₁ по числу секций с долей ≥1% и по доле таких секций с продольным соседом в том же модуле (п.п.). Одинаковый порог 1% позволяет сравнивать гладкие генераторы; точные нули анализируются отдельно. Референс для каждой модели — транспортная симуляция этих же контрольных строк. На нулевой сумме возвращается нулевая карта. Публикуем значения для каждой инициализации и направления; единица наблюдения — строка архива.

Если знак разности ошибок зависит от вида или метрики, вывод делаем отдельно для каждого среза. Устойчивая разность между двумя обученными моделями характеризует эти реализации при выбранном бюджете. Изолировать геометрический предел GMM только по этому опыту нельзя. Сравнение с эмпирической формой показывает, оправдана ли замена простого условного генератора.
