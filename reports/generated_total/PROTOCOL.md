# Полная генерация отклика при заданном направлении

24 ноября 2026. До расчёта зафиксированы сохранённые CFM суммарного сигнала и три модели формы. Проверяем, сохраняется ли порядок по средней абсолютной ошибке частоты превышения модульного q95, когда T генерируется. Ожидаемый порядок ошибки по прежнему опыту при наблюдаемом T — эмпирическая форма, прямой WGAN-GP, интегральная GMM с WGAN-GP. Основной контраст — ошибка GMM минус ошибка прямого WGAN-GP в процентных пунктах.

Для µ⁺ и p отдельно, 3 и 5 зарегистрированных направлений, используем прежние обучающие и калибровочные наборы по 4096 строк и контрольные карты из опыта при известном T (4096 на направление). Этот контроль повторно используется для сравнения без настройки. Для каждой модели формы подаём одну и ту же последовательность из первых 4096 сумм сохранённой генерации CFM на направление. Одно обучение CFM на вид. Три прежних обучения каждого WGAN-GP и три розыгрыша эмпирической формы, seed 173, 283 и 397. Шумы прямого и интегрального декодеров согласованы. Проверяем состав входных выборок, сохранение сумм и конечность неотрицательных секционных сигналов. Модель получает вид, направление и сгенерированную сумму; контрольная транспортная строка с генерируемой картой физически не спарена.

Порог фиксирован на 95-м процентиле положительных калибровочных сигналов, отбираются модули с ≥500 положительными калибровочными строками. Частоту считаем по всем строкам направления. Усреднение — поровну по пригодным модулям внутри направления, затем по направлениям, затем по трём запускам. Дополнительно сравниваем частоту превышения такого же порога полной суммы, число секций с долей ≥1% суммарного сигнала и долю таких секций с продольным соседом по прежнему определению. Для последних двух распределений используем расстояние Вассерштейна W₁.

Для основного контраста строим процентильный 95%-интервал (400 повторов). В каждом направлении отдельно ресэмплируем транспортные и сгенерированные строки; одни и те же веса сгенерированных строк применяем ко всем моделям формы и seed, сохраняя общие T. Обученные модели, калибровка и направления фиксированы. Размах трёх запусков приводим отдельно. Если порядок меняется между видами или направление интервала неопределённо, ограничиваем вывод соответствующей выборкой и контрастом. Независимость строк транспорта требует подтверждения по идентификаторам первичных событий.
