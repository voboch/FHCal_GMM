# Генерация суммы и пространственного отклика FHCal для мюонов и протонов

Когда суммарный сигнал генерирует условный flow matching (CFM), наименьшую среднюю ошибку частоты превышения модульного порога q95 даёт эмпирическая форма. В ней секционные доли выбираются из одной из 16 ближайших по log T обучающих записей того же направления. Среди двух обученных генераторов формы прямой WGAN-GP в среднем точнее WGAN-GP с интегральной гауссовской смесью. Порядок для обоих видов совпал с [опытом при известной сумме](../conditional_shapes/RESULTS.md).

## Частота превышения q95 в модуле

| Форма при общем сгенерированном T | µ⁺, ошибка [п.п.] | p, ошибка [п.п.] |
|---|---:|---:|
| Эмпирическая | 0,81 (0,75–0,85) | 0,33 (0,32–0,36) |
| Прямой WGAN-GP | 2,24 (1,54–2,63) | 2,26 (2,12–2,40) |
| WGAN-GP с интегральной GMM | 4,28 (4,09–4,55) | 4,47 (3,46–5,93) |

В скобках указан размах трёх розыгрышей эмпирической формы или трёх независимых обучений WGAN-GP. Разность средних ошибок «GMM минус прямой выход» составила +2,03 п.п. у µ⁺ (95%-интервал 1,73–2,29) и +2,21 п.п. у p (2,16–2,24). В третьем мюонном направлении ошибка меньше у GMM, 1,89 п.п. против 3,50 у прямого выхода. [По направлениям µ⁺](muon_directions.csv) · [По направлениям p](proton_directions.csv).

Все методы получают одну последовательность из 4096 значений T на направление. Контроль включает 12 288 мюонных и 20 480 протонных транспортных строк из опыта при известной сумме. Модели и пороги были зафиксированы до оценки. Порог определяется отдельно для каждого модуля и направления как q95 положительных калибровочных сигналов при наличии ≥500 таких сигналов. Частоту превышения считаем по всем 4096 строкам направления. Абсолютные ошибки усредняются по модулям внутри направления, затем по направлениям и трём запускам. Критерию удовлетворяют 6 мюонных и 123 протонные пары «модуль × направление». [Счётчики µ⁺](muon_modules.csv) · [Счётчики p](proton_modules.csv).

## Полная сумма и пространственная структура

У мюонов CFM чаще транспорта превышает q95 суммарного сигнала во всех трёх направлениях. Числа превышений (CFM / транспорт) составили 263/203, 257/192 и 290/215 при 4096 записях каждого источника на направление. Средняя абсолютная ошибка частоты равна 1,63 п.п. Для протонов она равна 0,93 п.п. по пяти направлениям. Все три метода формы сохраняют заданную сумму каждой реализации. [Полная сумма µ⁺](muon_totals.csv) · [Полная сумма p](proton_totals.csv).

| Форма | W₁ числа секций, µ⁺ / p [секции] | W₁ доли секций с продольным соседом, µ⁺ / p [п.п.] |
|---|---:|---:|
| Эмпирическая | 0,04 / 0,21 | 0,17 / 0,52 |
| Прямой WGAN-GP | 0,70 / 4,27 | 1,88 / 13,41 |
| WGAN-GP с интегральной GMM | 0,67 / 8,06 | 7,06 / 18,42 |

Учитываются секции с долей ≥1% полной суммы. Сосед — секция выше того же порога в смежном продольном слое того же модуля. Долю с соседом задаём равной нулю для пустой карты. Для каждого направления и запуска W₁ сравнивает распределение модельной величины с транспортом. В таблице приведено среднее по направлениям и запускам. [Численный экспорт](summary.json).

## Область вывода и воспроизведение

Проверены дискретные направления и одно сохранённое обучение CFM на вид частицы. Порядок ошибок характеризует испытанные генераторы при этом бюджете. Для доверительного интервала ресэмплировали контрольные и генерируемые строки независимо внутри каждого направления, сохраняя общие индексы генерируемых T между методами и запусками. 400 повторов учитывают конечный объём двух выборок при фиксированных порогах и весах сетей. Интерпретация интервала по транспорту предполагает независимость строк, которую ещё предстоит сверить по первичным ID.

Из корня FHCal_GMM при наличии сохранённых checkpoint и подготовленных выборок:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 MPLBACKEND=Agg python src/evaluate_generated_total.py
```
