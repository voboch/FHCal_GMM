# Протокол экспериментов FHCal GMM

## Данные и область применимости

Прототип моделирует секционный отклик FHCal для пяти записанных направлений
протонов. Для каждого направления банк хранит параметры смеси и суммарный
сигнал одних и тех же строк. При генерации строку выбирают целиком.
Номер секции служит продольной координатой в основном декодере.
`E_vis` обозначает сумму сигнала по считываемым секциям.

Диагностика аппроксимации использует отдельные мюонный и протонный
экспорты. В них известны записанные PDG, импульс и вершина. Исходные ID
событий, первичную множественность и физическую карту требуется сверить
по заполненному ROOT. До такой сверки единица анализа — строка экспорта.
[Исходный протокол мюонного пилота](../src/gaussian_projection/README.md).

## Оценка

В построчных подгонках наблюдаемая сумма задаёт нормировку, а точность
формы оценивается по долям сигнала. Для парного сравнения операторов
используются одни и те же строки. Интервал оценивается для их разности.
При генерации сравниваются распределения референсных и сгенерированных
откликов отдельно для каждого направления. Оценка включает суммарный
сигнал, энергию по модулям, занятость, продольный профиль и соседство секций.
Масса в нулевых секциях измеряется относительно наблюдаемого носителя.

## Условный генератор

Гладкий декодер интегрирует компоненты смеси по секциям и нормирует
их на поддержке детектора. Стохастический декодер разыгрывает секции
для порций каждой компоненты. При одинаковых параметрах смеси оба
декодера сохраняют её полный сигнал. Число порций выбирали по
отдельной калибровочной выборке. Команды запуска и повторной подгонки
описаны в [инструкции по воспроизведению](../PIPELINE.md).

### Инженерный прогон банка смесей на протонах

Проверить, что выборка параметров по записанному направлению
воспроизводит распределения на отложенных строках, и измерить
потери от гладкого представления. Источник тот же протонный NPZ.
Исключить все строки протонных диагностик, затем случайно выбрать
без возвращения 32 строки в банк и 256 в отложенную выборку для
каждого из пяти точных векторов импульса. Seed разбиения 20261120.
Проверить отсутствие точных дубликатов записи между ролями по
записанному импульсу, вершине и секционному отклику. Единица
сравнения — строка. Независимые исходные ID требуют ROOT.

На банк подогнать интегральную смесь $K=6$ с тремя стартами,
лимитом 800 итераций и минимумами ширин $(2{,}5,2{,}5,0{,}175)$.
Сохранять конечное решение с наименьшей потерей и его статус.
Выбирать равновероятно целую пару параметров и полного сигнала
из группы направления. Сопоставить с выборкой исходных откликов
из того же банка и с выборкой из объединённого банка без условий.
Для двух условных вариантов использовать одни и те же строки и
веса. Сеть и стохастический декодер отложить до сравнения этих
контролей. Вершина используется для проверки дубликатов.

В каждой группе считать $W_1$ относительно отложенных строк для
суммарного сигнала, числа секций с долей от 1 %, числа положительных
секций, максимальной доли и средней глубины на непустом отклике.
Среднее по группам равновзвешенное. Для разностей $W_1$ перевыбирать
строки банка и референса независимо внутри направлений, используя
одни и те же перевыборки в сравниваемых вариантах (1 000 повторов).
Ожидается точное согласие двух условных методов по сумме, выигрыш
условного контроля у объединённого порядка одной единицы сигнала
и ухудшение $W_1$ занятости гладкого декодера порядка 1–3 секций по
ориентиру пилота. Это инженерные прогнозы. Достаточно подтвердить
целостность генерации и описать потери на этом разбиении.

### Калибровка стохастического декодера

Использовать готовый банк из 32 смесей на направление. Сохранить
параметры смеси, вес выбора записи и сумму сигнала. Сравнить
гладкое интегрирование с выборкой одинакового числа порций из
каждой компоненты, сохраняя энергию компоненты. Исходный экспорт
используется без порога считывания. Порог 1 % определяет только
метрику занятости.

При seed 14717 выбрать по 128 калибровочных и 256 контрольных строк
на направление. Исключить строки банка, предыдущую отложенную
выборку и строки протонных диагностик. Сверить суммы и дубликаты
между выбранными ролями. Перебрать $N=4,8,16,32,64,128,256,512,1024$
порций на компоненту, по 32 реализации на запись банка. Ожидается,
что $W_1$ числа ненулевых секций уменьшится на сотни секций, поскольку
гладкий декодер заполнял почти всю карту. Сдвиг занятости при пороге
1 % зависит от выбранного $N$ и заранее открыт.

На калибровочных строках минимизировать $W_1$ точной занятости при
допустимом увеличении $W_1$ для занятости от 1 % на одну секцию,
максимальной доли на два процентных пункта и средней глубины на
0,10 секции. Это инженерные допуски для сравнения декодеров.
Если ни один вариант их не проходит, выбрать минимум суммы превышений,
делённых на допуски, затем минимум $W_1$ точной занятости. При равенстве
брать меньший $N$. Оценить выбранный $N$ на контрольных строках с новым
seed генерации. Для интервала разности использовать 1 000 перевыборок
целых записей банка и строк контроля внутри направления, при этом
32 реализации одной записи перевыбирать вместе. Единица интервала —
строка архива при допущении независимости. Сравнение проверяет
локализацию и распределение по глубине в пределах фиксированного банка.

### Диагностика распределения сигнала по секциям

На тех же 1 280 контрольных строках провести вторичный анализ
зафиксированного декодера. Число порций, банк, seed контрольной
генерации и разбиение взять из сохранённой калибровки. К гладкому
и стохастическому вариантам добавить исходные отклики тех же
записей банка с теми же весами. Это сравнение показывает, какая
часть расхождения появляется при кодировании гладкой смесью и
какая при выборке порций.

Проверить число ненулевых секций, число секций с долей не менее
1 %, число секций с меньшим ненулевым сигналом и долю суммарного
сигнала в таких секциях. Сравнить по направлениям распределения
и средние. Ожидается, что сокращение точной занятости почти на 400
секций придётся на слабые сигналы. Из известного сдвига за счёт
порций порядка 0,2 секции ожидается, что дефицит секций с заметным
сигналом будет виден уже после гладкого декодирования. Сравнение
с исходным банком проверяет это ожидание.

Для каждого события посчитать долю ненулевых секций с хотя бы
одним ненулевым соседом в предыдущей или следующей секции того же
модуля. Повторить при пороге 1 %. Это мера продольного соседства.
Сравнить $W_1$ по направлениям и разности средних $W_1$ с парными
95%-ми интервалами из 1 000 перевыборок строк банка и контрольных
строк. Все реализации одной записи перевыбираются вместе.
Направление и величина сдвига по соседству заранее открыты.

Пример для рисунка выбрать в группе 3 по ближайшему к медиане
числу секций с долей от 1 % в исходном банке, с меньшим индексом
NPZ при равенстве. Показать исходную строку, её гладкий отклик и
первые две стохастические реализации. Выбрать четыре модуля с
наибольшим суммарным сигналом в исходной строке. Формулировки
ограничить распределениями и продольным соседством на этом
экспорте. Статистические выводы условны на независимость строк.

### Распределения суммарного сигнала и сигнала модулей

Для протонов использовать те же 1 280 контрольных строк, 160 записей
банка и фиксированное зерно контрольной генерации. Суммировать сигнал
по секциям каждого из 54 модулей и по всей карте. Сопоставить исходный
банк, гладкий и стохастический декодеры с контрольными строками отдельно
по направлениям. Для каждой группы и каждого модуля сохранить долю
точных нулей, $W_1$ без отсечения нулей, квантили 10, 50 и 90 % и
гистограмму при положительном сигнале. Границы гистограмм общие
внутри архива, выход за последнюю границу учитывается отдельно.
Исходный банк и декодеры должны совпадать по распределению полной суммы
до численной точности. Насколько декодеры меняют асимметрию модулей,
заранее открыто. Показать в деталях два модуля с наибольшей частотой
сигнала от 1 % полного отклика в исходном банке направления 3.
Для протонов оценки описательные, с зафиксированными строками банка.

В исходном мюонном NPZ для трёх точных векторов PDG −13 взять по
2 048 строк для выбора и подгонки и по 4 096 для проверки без
возвращения, исключив строки прежнего пилота. Seed 2371. Сверить
суммы, карту и модуль импульса. Угол считать к оси $+z$ экспорта.
Для иллюстрации асимметрии выбрать на обучающих строках самый частый
ненулевой модуль в группе с минимальным углом к $+z$. На его положительном
сигнале сравнить нормальную плотность и свёртку Ландау с гауссом, обе
условные на $E_m>0$. Границы интервалов взять из квантилей подгонки,
с хвостом до бесконечности. На контрольных строках сравнить среднюю
отрицательную логарифмическую вероятность этих интервалов и квантили.
Ожидается меньшая ошибка свёртки для правого хвоста, порядок выигрыша
открыт. Для разницы логарифмических потерь использовать парный бутстреп
из 1 000 перевыборок контрольных строк при условии их независимости и фиксированных
подгонках. Модель здесь описательная. Физическая проверка для нормального
падения требует подтверждённых траекторий и параметров считывания.

### Проверка веса поглотителя в продольной координате

В опубликованной конструкции FHCal секция объединяет шесть
сцинтилляционных пластин. Для проверки использовать повторяющуюся
укладку Pb 16 мм и полистирол 4 мм, порядок Pb–сцинтиллятор.
Плотности 11,35 и 1,06 г/см³. Это приближение опубликованной
геометрии. Порядок пластин, торцевые слои и точная укладка
использованного архива требуют сверки по исходной геометрии ROOT.

Сопоставить старый интеграл по целой секции, интеграл только по
шести активным пластинам в геометрической глубине и такой же
интеграл в массовой глубине $t=\int\rho(z)\,dz$. Нормировать
глубину на толщину одного повторяющегося периода секции в выбранной
координате. Свинец влияет на расстояния в $t$, видимый сигнал
интегрируется по активным интервалам. При одинаковых секциях
массовая глубина границ отличается от глубины в сантиметрах
постоянным масштабом, поэтому существенный эффект возможен только
за счёт изменившихся интервалов активных пластин внутри секции.

Использовать те же 160 строк банка, 1 280 контрольных строк,
шесть компонент, три старта и лимит 800 итераций. Сохранить тот же
минимум продольной ширины в единицах секции и зерно старта. В
стохастическом варианте зафиксировать 128 порций на компоненту,
32 реализации на запись и прежнее зерно генерации. Сравнить $W_1$
доли секций с продольным соседом для точной занятости и при пороге
1 %. Сохранить TV подгонки, сумму и $W_1$ числа занятых секций.
Ожидаемый эффект плотности в регулярной укладке мал, порядка
одного или нескольких процентных пунктов. Парные интервалы строить
из 1 000 перевыборок банка и контроля внутри направлений отдельно.
Первоначальный критерий требует, чтобы интервал улучшения исключал
ноль, уменьшение $W_1$ соседства превышало 2 п.п. и ухудшение
$W_1$ занятости от 1 % было меньше одной секции. При интерпретации
результатов этот критерий применён к сравнению массовой глубины
с интегралом по целой секции для всех ненулевых секций.
С 2 п.п. сравнивается точечная оценка, отдельно проверяется, что
95%-й интервал исключает ноль. Сравнение двух интегралов по активным
пластинам оценивает смену параметризации, при одинаковом материале
исходной симуляции и повторной подгонке на тех же строках.

## Расширение пилота на пионы

Сначала получить симуляционный экспорт FHCal для одного знака заряда
и одного записанного вектора импульса. Для π⁺ использовать PDG 211,
для π⁻ — PDG −211. Сверить с ROOT первичную множественность, исходные
ID, единицы и карту секций. Снимок геометрии мюонов применим при
подтверждении той же геометрии и укладки. Референс — секционный
отклик пиона из этого экспорта.

Повторить сравнение интеграла и центра × объём с $K=1,2,4$ при
исходных и уменьшенных минимумах ширин. Ориентир для сопоставимости
с мюонным пилотом — две раздельные подвыборки по 48 строк, три старта
с лимитом 200 итераций и те же настройки. С ростом $K$ ожидается уменьшение
TV, инженерный ориентир мюонного пилота — разность порядка 0,02.
Направление парного контраста операторов для пионов открыто.
Показать среднюю TV, сигнал в секциях с наблюдаемым нулём,
статус оптимизации и примеры около трёх процентилей. Для интервала
парного контраста перевыбирать исходные события или документированные
группы. Если известны только строки, явно оговорить их условную
независимость, как в мюонном пилоте. Полный отклик при этой подгонке
задаётся наблюдением.

Локальный оценщик принимает `--pdg 211` или `--pdg -211` и
`--momentum PX PY PZ` для выбора подтверждённого импульса. Формат
текущего оценщика — секционный экспорт `EnergyDeposit[N,7,9,10]`.
Физический формат ветки `[N,54,10]` требует явной сверки
`ModuleIds`, маски и сумм при приведении к общей карте.
[Команды оценщика](../src/gaussian_projection/README.md).

### Занятость и чувствительность к лимиту оптимизации

Для тех же 96 строк посчитать число секций с положительным
наблюдаемым сигналом и число секций с долей не менее 1 % суммы.

### Число компонент после проверки бюджета

инициализации и три старта на вариант. Параметры стартов зависят
от $K$. Ожидаем снижения TV при росте $K$. Разность 0,02 в долях
TV служит описательным инженерным ориентиром из исходного пилота.
Показать парные изменения, статусы оптимизатора и цену представления
в координатах формы ($7K-1$). Сетка диагностирует выигрыш на
подогнанных строках. Выбор рабочего $K$ для генерации требует
отдельной выборки, критериев качества и оценки полной стоимости.

В каталоге `proton_replay` из блока выше можно повторить

### Зависимость ошибки подгонки от входа и наблюдаемого отклика

В поисковом анализе на прежних 96 строках сравнить TV интегральной
смеси при $K=4,6,8$ и выигрыш $\mathrm{TV}_4-\mathrm{TV}_8$.
Проверить связи с полной суммой, числом ненулевых секций, числом
секций с долей не менее 1 %, эффективным числом секций
$1/\sum_i f_i^2$, средним индексом глубины и разбросом по глубине.
Отдельно проверить три координаты записанной вершины. Ожидаем, что
более распределённый отклик сложнее аппроксимировать. Сумма и
наблюдаемые формы доступны только при диагностике. Показать все
заданные ранговые корреляции и срез с 31 ненулевой секцией и выше.
Отбор признаков по значимости и причинная трактовка здесь не нужны.

Для сравнения входных условий взять по 48 строк с seed 19 из
каждого из пяти записанных векторов импульса в том же протонном
NPZ. Использовать интегральную ветку при $K=6$, три старта,
800 итераций и уменьшенные минимумы ширин. Группа из предыдущего
пилота берётся из его первого отбора без повторной подгонки.
Модули импульса почти одинаковы, поэтому сравниваются группы по
направлению. Физическая карта, первичная множественность и
независимые ID остаются неподтверждёнными. Различия между группами
могут включать различия источников и условий. Интервалы средних
бутстрепа строить внутри каждой группы по строкам с допущением
их независимости. Сравнение остаётся диагностикой подгонки.

Для повторения расчёта связей использовать зафиксированные экспорты
подгонок. Четыре файла `directions/group_*.json` получены оценщиком с
`--pdg 2212 --components 6 --maxiter 800 --min-scales 2.5 2.5 0.175`
и `--events-per-repeat 48 --seeds 19`. Точные аргументы `--momentum`
записаны в поле `selection.momentum` каждого файла.
