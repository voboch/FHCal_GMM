# Исследования FHCal

В начале задачи откройте [общий указатель thesis-kb](../../../thesis-kb/conventions/README.md) и применимые разделы. При другом расположении используйте каталог thesis-kb из THESIS_KB или локальной рабочей копии. Для эксперимента действуют §10 и §30, для отчёта §20 и §25, для диссертации также §40 и актуальный план. Научные условия конкретного опыта определяют его протокол и [состояние эксперимента](docs/experiment_state.md).

Для нового результата, изменившегося экспорта или подготовки материала применяйте [процесс thesis и реестр FHCal](research/README.md). До пересмотра зарегистрированного вывода выполните `python3 research/evidence.py impact <путь-экспорта>` из корня FHCal_GMM, проверьте затронутые материалы, затем обновите привязки и проверьте `python3 research/evidence.py check`. Перед цитированием прочитайте значения и ограничения через `claim`. Локальная редакторская правка требует проверки изменённого материала.

## Научные отчёты FHCal

Для отчётов, презентаций, таблиц и рисунков применяйте [правила научного изложения](docs/conventions/25-scientific-reporting.md), [правила представления результатов](docs/conventions/20-result-representation.md) и [редакторскую проверку no-ai-slop](docs/conventions/no-ai-slop.md). Для презентаций используйте [профиль локальной сборки Quarto](docs/conventions/profiles/scientific-presentations.md). Копии взяты из thesis-kb/conventions и раздела Writing: no AI slop проекта HGNDRecoGNN. Исторические примеры из HIC/HGND относятся к своим детекторам.

- Называйте метод, физическую величину и роль выборки при первом упоминании и на рисунках, которые можно читать отдельно. Для эмпирического распределения указывайте число исходных записей на направление. Различайте записи транспорта, события с подтверждённым ID и повторные реализации одного отклика.
- Подписи рисунков, названия панелей, осей, легенды и цветовые шкалы пишите на английском. Для оси указывайте величину и подтверждённые единицы. Для нормированной переменной укажите знаменатель, выборку для его оценки и условие отбора. Поясняйте вертикальные линии и выбор знаменателя для вероятностей.
- При проверке no-ai-slop прочитайте заголовки, основной текст, подписи и заметки. Замените внутренние названия и оценки важности описанием метода, наблюдаемой величины или проверяемого результата. Сохраните ограничения интерпретации, неопределённости и единицы анализа. Сверьте правку с численным экспортом и прочитайте конечный PDF. Поиск слов помогает обнаружить повтор известной ошибки, научный смысл проверяет редактор.
- Для содержательной переработки привлекайте независимого редактора с доступом на чтение по §25.2. Передавайте ему конечный рендер и источники чисел. Для локальной правки достаточно проверки изменённых элементов.

Для сводной презентации Quarto перед сборкой запускает `python3 reports/overview/check_wording.py` (команда из корня репозитория). Проверка находит известные проектные ярлыки и вводные штампы в тексте, а также кириллицу в подписях SVG.
