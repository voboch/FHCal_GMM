# FHCal GMM

Прототип быстрой симуляции секционного отклика калориметра FHCal в BM@N.
Условие модели — одно из пяти записанных направлений протона. Для каждого
направления в банке есть 32 подогнанные гауссовские смеси. При генерации
модель выбирает смесь и её суммарный сигнал вместе, а затем распределяет
сигнал по 438 секциям. Стохастический декодер разыгрывает энерговыделения
по секциям, гладкий интегрирует плотность смеси.

## Быстрый запуск на CPU

Проверено с Python 3.13. Команда генерирует отклики из банка в репозитории.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python inference.py -cn=proton_inference inferencer.direction=3 inferencer.events=100
```

В `outputs/proton_responses.npz` поле `section_energy` имеет форму
`[100, 438]`. Поля `module_id` и `layer` задают порядок секций. В том же
файле сохранены параметры смесей, исходные индексы и суммы откликов. Рядом
записывается `proton_responses.run.json` с конфигурацией и SHA-256.

Выберите `inferencer.direction` от 1 до 5. Записанные векторы импульса
приведены в [описании банка](src/gaussian_projection/proton_pilot/conditional_baseline/RESULTS.md).
Для гладкого декодера укажите `inferencer.decoder=smooth`. Стохастический
режим использует 128 порций на компоненту по калибровке банка. Команда
`python inference.py --cfg job` показывает итоговые настройки.
Относительные пути задаются от корня репозитория.

## Результаты

На 1 280 контрольных строках среднее число ненулевых секций — 25,74 в
симуляции и 25,66 у стохастического декодера. Кодирование гладкой смесью
снижает число секций с долей от 1 % полного сигнала с 17,26 до 13,76
на тех же строках банка. После розыгрыша порций их 13,61. Продольное
соседство у стохастического декодера остаётся выше референса.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| [`train.py`](train.py), [`inference.py`](inference.py) | Запуск с именованными конфигурациями |
| [`src/configs/`](src/configs/) | YAML для подгонки, калибровки и генерации |
| [`src/pipeline/`](src/pipeline/) | Геометрия, интегратор и подгонка смеси |
| [`src/gaussian_projection/`](src/gaussian_projection/) | Исходные численные экспорты, банк, калибровка, рисунки |
| [`reports/`](reports/) | Сводка и PDF |
| [`tests/`](tests/) | Проверки на CPU |

Численный код FHCal использует NumPy и SciPy. Запуск настраивается через YAML
и аргументы `поле=значение`. [Происхождение шаблона и данных](THIRD_PARTY.md).
